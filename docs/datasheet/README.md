# Datasheets (local copies)

Place vendor PDFs here (for example the **FDO2-G2** module datasheet and any
PyroScience unified protocol addenda for your firmware range). Paths under this
folder are ignored from strict driver linting in CI where applicable.

Official downloads remain the authoritative source; keep revision notes when you
update files in this directory.

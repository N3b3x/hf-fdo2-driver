Detailed Description

#VERS D N R S fields (FDO2-G2 data sheet §4.3).

Firmware revision R is encoded as integer hundreds, e.g. R=328 → 3.28. Expected for FDO2-G2: D=8, N=1, S=15 when all internal sensors are present.
